# The Walking Dead The Game

[Leia em português](README.pt-BR.md)

A third person game set in the world of The Walking Dead that runs in the browser, built with Next.js, React Three Fiber, three.js and the Rapier physics engine. The map is generated procedurally from a seed, with terrain loaded in chunks, forests, grass, water, a dynamic sky with sun shafts, small settlements and props and resources scattered around to interact with. There is a world atlas to see where you are, a compass on the HUD, walking and flying modes and touch controls with a virtual joystick for phones.

Besides the game there are two other pages. The blockout page is a workshop of post apocalyptic structures, with detailed modules, PBR textures, interiors you can walk into and a geometry audit, made to feed the city generation that comes later. The survivor page is a lab for the main character.

A lot of the content is generated by scripts in the scripts folder, which build the blockout, the textures, the vegetation, the structure footprints and the list of resources, and also optimize the final assets. The game adjusts its render resolution on its own to keep the frame rate steady.

This is a fan project with no connection to the owners of The Walking Dead.

## How to use

The 3D models are stored with Git LFS, so install it before cloning, otherwise you only get small pointer files instead of the GLB models. Then run pnpm install and pnpm dev and open localhost on port 3000. The world can be changed through the address, using seed to pick the world, x and z to pick the starting point and mode set to fly to start flying. The workshop is at the blockout path and the character lab at the survivor path.

pnpm test runs the tests and pnpm typecheck checks the types. pnpm assets builds the generated assets again.

## Development time

The game took two and a half weeks to build and it is finished in its current form.
